# Python-Assignment-3-While-Loop-For-Loop-and-Function

## Topics Covered
- While Loop
- For Loop
- Fuction
##  Programs Included

### 1. Number Guessing Game 
Where the computer generates a random number between 1 and 10, and the user tries to guess it.

**Features:**
- Generates a random secret number.
- Allows up to 3 valid attempts.
- Displays hints such as "Too high" or "Too low".
- Checks whether the guess is within the valid range.
- Reveals the correct number if all attempts are used.

### 2. Multiplication Table 
Takes a number from the user and prints its multiplication table from 1 to 10.

### 3. BMI Calculator 
Calculates Body Mass Index (BMI) using the user's weight in kilograms and height in meters.

**Formula:**

BMI = Weight (kg) / Height (m)²

**Features:**
- Accepts weight and height as user input.
- Calculates BMI using a function.
- Displays the result.
